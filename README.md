# Guía de Carriers de XNPC Financial

Herramienta interna bilingüe para que los representantes:

- comparen opciones preliminares de suscripción;
- consulten opciones por estatus migratorio y perfil de salud;
- estimen la compensación bruta del primer año por carrier y producto usando su nivel de comp FFL y la prima anual oficial.

Sitio público: https://theemariogarcia.github.io/xnpc-carrier-guide-es/

La calculadora usa las tasas de `FFL Comp Master Sheet - ADMIN COPY.xlsx`. Sus resultados son estimados: el representante debe usar la prima anual y el producto confirmados por el carrier y verificar la tabla de compensación vigente. La información de colocación también es orientativa y no garantiza elegibilidad, aprobación, tarifa ni cobertura.
